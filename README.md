## 🔬 研究方法

- **情感分析**: SnowNLP + 家电领域词典增强
- **LDA 主题模型**: gensim 实现, K=5
- **Word2Vec**: Skip-gram, 200 维词向量
- **数据**: 京东家电评论 10,500 条（电饭煲/吸尘器/扫地机器人）

## 📊 核心发现

1. 家电评论正向情感占比 68.3%
2. 五大核心主题：产品质量、功能表现、物流配送、使用体验、性价比
3. 语义一致性对销量影响 (β=0.527) 超过情感得分 (β=0.327)
4. 综合模型调整 R² = 0.714
